## Known weaknesses (my own assessment)

1. **Coverage rose mostly through events that don't move the capacity sectors.** New oil-
   terminal / power / gas / coal events raise the count and coverage ratio, but oil logistics
   is a proxy, generation needs MW, and gas/coal are uncovered — so ESDI moved almost entirely
   through 3 linked refineries + substation strikes. The refinery-inventory is still not fully
   point-mapped, so curated strikes on other inventoried refineries under-count.
2. **Gas is uncovered.** LNG MTPA / processing bcm/y / pipeline bcm/y are incompatible; gas
   carries real GPP strikes that add 0. No defensible single-basis gas denominator has emerged.
3. **Coal has inventory but no disruption evidence** in the AOI — correctly score-0.
4. **Recovery is still thin (6 episodes).** The 47-day median mixes a 2-day port restart with
   a 205-day gas-plant repair.
5. **The context network is OSM-only** (major named transmission trunks ≥50 km); GEM GGIT/GOIT
   are form-gated (no CI URL), so all routes render as `osm_mapped` and the mapped/approximate
   distinction awaits a GEM snapshot.
6. **Transmission rests on a chosen saturation constant (8)** — a labelled convention.
7. **The WebGL map is pixel-unverified in the headless CI browser**; verified on the live
   production browser instead.

## Hard constraints — do not propose anything that breaks these

- Public, open, unclassified sources only. Never present an estimate as an observation.
  Analytic/monitoring tool, **not targeting**: no unit positions, readiness, vulnerability/gap
  analysis, ranking of undamaged assets, range-to-target, ingress/egress, or precise incident
  coordinates. **Map visibility ≠ analytic inclusion** — a context pipeline crossing excluded
  territory does not authorize scoring there. Free-tier static hosting; Windows dev machine.
- **Credibility over feature count.** Prefer fixing a denominator or tightening an evidence
  category to adding a view. Evidence ladder: **observation > sourced estimate > transparent
  proxy > model > unknown**. **Zero is a research question before it is an answer.**
