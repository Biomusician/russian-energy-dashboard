## Non-obvious things to know

- **`esdi_excluded` is currently EMPTY.** Occupied Crimea is `esdi_included=True` by an
  intentional iteration-4 choice and DOES feed the national ESDI (≈45% of transmission, +1.10
  ESDI). The mechanism is retained for any future excluded region. Don't reintroduce a docstring
  claiming occupied regions are fenced out — they aren't. (Red-team caught this in iteration 6.)
- **Never fix data by editing `data/processed/`** — it's a build artifact. Fix the curated
  source under `data/` and rebuild.
- **All Cyrillic file I/O in Python must pass `encoding="utf-8"`** (cp1252 default corrupts silently).
- Research episodes (recovery/effects) must be **re-sourced from public news with real URLs**, never
  reconstructed from memory — iteration 6's agent findings were lost to compaction and re-run.
