## Iteration 13 end state (theme: the commit, the citation, and the assumption)

See [ITERATION_13_REVIEW.md](ITERATION_13_REVIEW.md).

**The shape of all three defects was the same**: a correct component, an unchecked seam, and a
passing test reading the layer *before* the one that ships. 367 tests passed over all of them.

**What a new session most needs to know.**

- **`pipeline/artifacts.py` is the single declaration of what a build produces.** Adding a
  generated artifact there is what makes it staged, manifested and asserted. Do not add a second
  file list anywhere; three independent lists is how `docs/CURRENT_STATE.md` shipped stale in
  twenty-nine consecutive bot commits while a test validated it on every run.
- **`refresh.yml` runs `pytest -m "not repo_hygiene"`; `ci.yml` runs everything.** A test that
  reads this repository's prose or frontend source must carry `@pytest.mark.repo_hygiene`, or it
  can freeze the daily data publication. Writing the iteration-13 review would have done exactly
  that. Four meta-tests enforce the partition; `--strict-markers` is on, so a misspelled mark is
  an error rather than a silent no-op.
- **`ci.yml` fires on `workflow_run`, not just `push`.** GitHub does not trigger push workflows
  for `GITHUB_TOKEN` pushes, so for fourteen bot commits CI never ran at all. If CI stops
  appearing on dataset commits, that trigger is the thing to check.
- **The daily refresh verifies its own staged tree** (`scripts/verify_staged.py`) before
  committing. It is allowed to block publication because an internally inconsistent artifact is
  worse than none — and unlike the iteration-12 outage it contains no arithmetic and cannot rot.
- **Citation alignment matters to the score, not just to display.** The source writes
  `DATE,<ref>` — comma first — and `_realign_fragments` exists because of it. `_confidence` is a
  pure function of distinct cited hosts and multiplies exposure by 0.45–1.0, so a citation on the
  wrong date is a 2.2x weighting error. The cheap detector is in the suite: a news report cannot
  predate the strike it describes.
- **One physical facility, one scoring key.** `facility_identity()` collapses ids the canonical
  refinery registry calls the same plant, and the fold is disclosed via `merged_asset_ids`.
  Curated ids are `refinery-<place>` and parsed ids are `<place>-refinery`, so this will be
  needed again.
- **A tracked file's evidence date is its commit date, not its mtime.** `actions/checkout` sets
  every mtime to now, so mtime is only meaningful for the untracked download cache.
- **The headline rests on an assumption, and now says so.**
  `snapshot.recovery_horizon_sensitivity` sweeps the modelled reconstitution horizon; roughly 52
  of 54 live facilities decay on it. Halving and doubling moves the headline by more than 3x.

**Open, and deliberate.** The refining numerator (strike table) and denominator (curated
registry) are on different bases, differing by ~6% overall and 2.3x for TANECO; two denominator
members contribute zero because their source rows have no capacity cell, worth ~1.4 headline
points. Quantified in `snapshot.impairment_not_sized`, written up with options in
[REFINERY_CAPACITY_BASIS.md](REFINERY_CAPACITY_BASIS.md), **not deployed** — it is a methodology

## Iteration 12 end state (theme: the refresh stopped and nothing said so)

See [ITERATION_12_REVIEW.md](ITERATION_12_REVIEW.md).

**What happened.** On 2026-09-21 the assertion `E_esdi_if_transmission_removed <= esdi` began
failing. It is mathematically false — the ESDI is a weighted MEAN, so excluding a sector whose
value sits below the mean of the others raises it — and had been true only while transmission
happened to be the above-average sector. `refresh.yml` gates its commit on the suite, so eleven
consecutive good builds were discarded and production served 2026-09-20 data for eleven days,
with the header still reading "live".

**What that produced, in order of importance.**

1. **Publication freshness.** The payload carries its cadence and thresholds
   (`PUBLICATION_CADENCE`, `pipeline/config.py`) and deliberately NO precomputed age — an age
   computed at build time freezes with the build and would read "0 days old" forever on a
   dashboard that had stopped rebuilding. The browser does the arithmetic against the reader's
   clock. Surfaces: a full-width strip above the ribbon, the ribbon's "live" suffix (now earned
   rather than assumed), a block leading the Data Quality panel, the briefing overlay, and the
   exported PNG. Unknown, unclassifiable and stale are kept as three different answers.
2. **Time bombs.** A test-architecture audit, driven by rebuilding the dataset at future dates,
   found five more assertions true only at today's values — each able to freeze publication the
   same way. Replaced with invariants or loud skips, and re-verified at 2026-12-15, 2027-01-31,
   2027-03-15, 2027-07-15, 2027-09-15 and 2028-06-01.
3. **A zero that lied.** New zero category `COVERED_IMPAIRMENT_WITH_NO_CAPACITY_FIGURE`. A
   facility can sit in a scored sector and still contribute exactly 0.00 because it carries no
   capacity figure, so `_share` has no numerator. Eight regions in the live payload — Moscow and
   Volgograd among them — were publishing "Nothing is recorded as impaired" about regions with
   live recorded impairment.
4. **Links.** Prototype-named values (`?r=constructor`) found phantom regions and could white-page
   the app; the "none" filter produced links that showed the recipient MORE than the sender saw;
   there was no error boundary anywhere.
5. **Exports.** A filtered frame did not say it was filtered; the events headline printed the
   whole-corpus total beside a scrubbed map; the Legend checkbox had never been read by anything;
   turning the title off removed every date from the image.
6. **CI.** `ci.yml` runs the frontend and the Python suite on push and pull request. Deliberately
   NOT added to `refresh.yml`: the set of things able to freeze publication must be as small as
   the job that publishes.

## Iteration 9 end state (theme: pipeline network from real sources — data/GIS, not scoring)

Merged from `iteration-9`. See [ITERATION_9_REVIEW.md](ITERATION_9_REVIEW.md).

**The context network is now reconstructed from OSM route RELATIONS, not loose ways.** The old
builder applied a 50 km minimum to each OSM *way*, required a name on each way, queried bands that
left 56–120°E unasked, and deleted anything the analytic feed also had. That cost 161,899 km of
relation-member geometry and hid the entire Russian trunk backbone whenever the analytic layer was
off. Gas went 220 routes / 29,832 km -> 375 routes / 164,563 km; oil 75 / 12,630 -> 89 / 51,385.

Rules that are now structural, and are tested:

- **Reconstruct the route, then judge it.** The trunk threshold applies to the ASSEMBLED route.
  84 routes exist only because assembly precedes the filter.
- **Proximity is not connection.** Segments join only on exactly-shared endpoints. The single
  distance rule (`weld`, <=100 m) applies ONLY between components of the same relation, and is
  counted per route. The named-way path never welds.
- **The context layer is self-contained.** Overlap with the analytic feed is MARKED
  (`analytic_overlap`), never deleted; the frontend suppresses double-draw.
- **Topology known != geometry known.** 54 sourced connection assertions live in
  `data/curated/pipeline_topology.csv`; two tests stop them ever becoming a drawn line.
- **Route quality is MEASURED** from source vertex density, never asserted.

**Traps a future session will hit:**

- Douglas-Peucker must measure to the SEGMENT, not the infinite line. The infinite-line metric
  erased 690 components / 216 km before it was caught. **Fixed in iteration 10:**
  `geo.segment_distance` is now the single implementation and `build_assets`, `build_context`,
  `build_pipeline_network` and `geo.simplify_ring` all use it. `_perpendicular_distance` remains
  only as a deprecated alias with no callers; a test enforces that there is exactly one metric.
- Open-line DP applied to a CLOSED chain deletes it: `simplify_line` keeps first and last, which
  on a loop are the same point, and the component then falls below 2 points. That silently
  dropped 646 components / 201 km. `_simplify` now dispatches to `simplify_ring` for closed
  chains. Same failure class as the erasure bug, different door.
- `weld()` must never join two chains whose endpoints are IDENTICAL. A zero-length "gap" means
  `stitch()` already saw that node and refused to walk it, because it is a junction of degree
  != 2; welding there re-joins what the junction rule separated. It was doing 119 such welds.
- OSM models some systems as a superroute PLUS its child relations, so summing route lengths
  double-counts ~25,500 km. Use `distinct_network_km`, not `total_length_km`, for network extent.
  `distinct_network_km` is now an EXACT union of member-way lengths; until iteration 10 it
  apportioned route length by way COUNT, which was order-dependent (a 5,638 km spread across
  orderings) and credited a whole corridor to whichever relation the loop reached first.
- OSM `substance=oil` covers refined products too. Exolum tags 235 members `oil` and zero `fuel`;
  only the NAME rule excludes it.
- ENTSOG has **no pipeline entity** — operator/point/balancing-zone only — and its `tpMapX/Y` are
  schematic, not lat/lon.
- GEM wiki **status** fields are stale (it says Ukraine transit is operating; it stopped
  2025-01-01). Where a tracker and a TSO disagree on status, the TSO wins.

## Non-obvious things to know

- **`esdi_excluded` is EMPTY.** Occupied Crimea is `esdi_included=True` and DOES feed the
  headline. Never write a comment or doc saying occupied regions are fenced out — a lint test
  fails the build if you do. (It shipped in iterations 5 and 6, and `METHODOLOGY.md` §7.2 still
  said Crimea was excluded until iteration 12; the lint missed that one because the sentence
  named neither "composite" nor "the index".) Its share of the transmission burden is published
  in `transmission_concentration.occupied_share_pct` — read it there. This bullet used to quote
  the figure inline, and the quoted figure decayed.
- **Transmission is "Transmission burden"**, an event-burden proxy against an arbitrary saturation
  of 8 — never "% of grid offline". ~45% is Crimea. The formula is retained deliberately; a future
  pass could revisit it.
- **The refining base is a conservative single-source vintage** ~10-15% below nameplate. This does
  NOT bias the refining *exposure* (a capacity share is invariant under uniform revaluation); it
  only understates the absolute MTPA + the completeness ratio. A uniform nameplate revaluation is a
  candidate future change.
- **Never fix data by editing `data/processed/`** — it's a build artifact. Fix the curated source
  and rebuild. All Cyrillic Python I/O must pass `encoding="utf-8"`.
- **Infrastructure symbology has ONE source of truth: `web/src/icons.ts`.** Add or change a class
  glyph there and it updates the map, the filter rows, and the legend together. Never hardcode a
  shape in a component. The map registers icons via local rasterisation only — do not reach for a
  glyph endpoint or sprite CDN (it would break the zero-network invariant).
- **The committed data is a CURRENT-DATE build.** (This bullet previously said the opposite — that
  the payload was pinned to the frozen 2026-08-28 reference. That was the iteration-8 mistake,
  corrected later in that same iteration; the stale wording survived and contradicted the "two
  builds" table above it until iteration 10.) A plain `python -m pipeline.run` is correct and is
  what the refresh bot runs. `--as-of 2026-08-28` is **comparison-only** and must never be
  committed; `test_release_payload_is_a_current_date_build_not_a_frozen_reference` fails the suite
  if it is, and `test_docs_do_not_claim_the_release_payload_is_frozen` fails if a doc starts
  claiming otherwise again.
- **MapLibre only allows `["zoom"]` as the direct input to a top-level interpolate/step.** Nesting
  it inside a `case`/comparison makes `addLayer` reject the layer silently (it fires an error event,
  doesn't throw). If a map layer "disappears", check its paint expressions for a nested `["zoom"]`.
- **`window.__map` exists only in dev** (`import.meta.env.DEV`) for map debugging; it is stripped
  from production builds.
- **Research episodes must be re-sourced from public news with real URLs**, never reconstructed from
  memory (agent findings are lost to compaction).
